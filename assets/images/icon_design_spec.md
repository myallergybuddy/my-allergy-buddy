# My Allergy Buddy Icon Design Specification

## Overview
A modern, professional icon that represents the core functionality of the My Allergy Buddy app:
- **Barcode scanning** for allergen detection
- **Medical/health theme** for allergy management
- **Safety and protection** for users with allergies

## Design Concept
A modern, professional icon that represents the core functionality of the allergy app:
- **Barcode scanning** for allergen detection
- **Medical/health theme** for allergy management
- **Safety and protection** for users with allergies

## Color Scheme
- **Primary**: #4A9E9C (Teal - matches app theme)
- **Secondary**: #FF6B6B (Red - medical/alert color)
- **Background**: White
- **Accent**: #3A8E8C (Darker teal for depth)

## Icon Elements

### 1. Background
- Circular design with teal gradient
- Outer ring: #4A9E9C
- Inner ring: #3A8E8C
- Center: White circle

### 2. Barcode Scanner Frame
- White rectangular frame with rounded corners
- Teal corner brackets at each corner
- Multiple barcode lines in the center
- Red scanning line animation effect

### 3. Medical Cross
- Red circle with white medical cross
- Positioned at the top of the icon
- Represents health/allergy theme

### 4. Safety Shield
- Teal shield shape with white inner
- Green checkmark inside
- Represents safety and protection

## Technical Specifications
- **Size**: 1024x1024 pixels
- **Format**: PNG with transparency
- **Style**: Flat design with subtle shadows
- **Platform**: Works for both Android and iOS

## Alternative Designs

### Option 1: Simple Scanner
- Just the barcode scanner frame
- Clean, minimal design
- Easy to recognize at small sizes

### Option 2: Medical Focus
- Medical cross as main element
- Barcode scanner as secondary
- Emphasizes health aspect

### Option 3: Safety Focus
- Safety shield as main element
- Medical cross and scanner as supporting elements
- Emphasizes protection aspect

## Implementation
1. Create the PNG file at 1024x1024
2. Place in `assets/images/icon.png`
3. Run `flutter pub get`
4. Run `flutter pub run flutter_launcher_icons:main`
5. Test on device

## Recommended Tools
- **Figma** (free online design tool)
- **Adobe Illustrator** (professional)
